# energizee.github.io

My portfolio website for projects I have done, and info about me.

Live at <https://leeelder.dev>
## Development

Built with [Astro](https://astro.build). Pages live in `src/pages`, shared pieces
in `src/components` and `src/layouts`, and static files in `public`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

Pushing to `main` builds and deploys through `.github/workflows/deploy.yml`.
